# PinShift 1.0.0

在 macOS 上通过地图选点，为 USB 连接的 iPhone 设置或清除模拟定位。

## 下载与安装

在本页 Assets 下载 `PinShift-1.0.0-macos-arm64.dmg`，打开后将 PinShift 拖入“应用程序”。应用已包含 Python、Qt 和设备通信依赖，无需自行安装开发环境。

- 当前下载包仅适用于 **Apple 芯片 Mac（M 系列）**，不支持 Intel Mac。
- 应用界面为中文。
- 首次使用须在“配置”中填写自己的高德 Web JavaScript API Key 及安全密钥，并连接网络。
- USB 连接一台 iPhone，解锁并信任 Mac，按设备要求开启开发者模式。
- iOS 17+ 会尝试自动建立 tunnel，特定情况下需要 macOS 管理员授权。
- 使用结束后主动点击“清除虚拟定位”；关闭窗口不保证清除定位。

当前包为 ad-hoc 签名，未做 Developer ID 签名及 Apple 公证。下载后 macOS 可能拦截启动。仅在确认下载来源可信后，按照系统提示到“系统设置 → 隐私与安全性”中选择“仍要打开”；不同 macOS 版本的提示可能不同。

## 功能

- USB 设备扫描，显示名称、系统版本及 UDID。
- 地图点击、地点搜索、坐标显示和复制。
- 设置 / 清除 iPhone 模拟定位，以及 GCJ-02 / WGS-84 坐标转换。
- Mac 当前位置、记住选点、启动行为配置。
- 日间 / 夜间主题、日志及关于信息。

## 校验

同时下载 `SHA256SUMS.txt`，在两个下载文件所在目录执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## English

PinShift 1.0.0 selects map locations on macOS and sets or clears simulated location on one USB-connected iPhone.

Download `PinShift-1.0.0-macos-arm64.dmg` from Assets and drag PinShift into Applications. Python, Qt, and device communication dependencies are bundled. This package supports **Apple Silicon Macs only**, with a Chinese UI. Supply your own AMap Web JavaScript API credentials and internet access. Unlock and trust the connected iPhone, and enable Developer Mode when required. iOS 17+ tunnel creation may request administrator authorization. Explicitly clear simulation when finished.

The build uses an ad-hoc signature and is not Apple-notarized. macOS may block downloaded applications; only if you trust the source, follow the system's Privacy & Security prompts to open it. Verify the download with `shasum -a 256 -c SHA256SUMS.txt`.

UI, map, bundle metadata, license inclusion, and signature checks passed. Clean installation on another Mac and comprehensive macOS / iOS hardware compatibility remain unverified.
